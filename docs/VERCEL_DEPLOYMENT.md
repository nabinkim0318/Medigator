# Cloud deployment status

No Vercel, Railway, production, or staging deployment is currently configured
or verified by this repository.

Legacy `vercel.patient.json` and `vercel.doctor.json` prototype artifacts were
removed because their placeholder Railway backend URLs did not describe an
implemented service. The repository provides no cloud deploy command or
environment configuration.

The only verified container target is the local/demo workflow documented in
the root README and `docker/README.md`. Do not describe it as a production
deployment.

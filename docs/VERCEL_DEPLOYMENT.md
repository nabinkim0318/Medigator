# Cloud deployment status

No Vercel, Railway, production, or staging deployment is currently configured
or verified by this repository.

The checked-in `vercel.patient.json` and `vercel.doctor.json` files are legacy
prototype artifacts. They are not part of the supported startup path, and the
repository does not provide deploy commands for them. In particular, their
placeholder backend URLs are not implemented services.

The only verified container target is the local/demo workflow documented in
the root README and `docker/README.md`. Do not describe it as a production
deployment.
